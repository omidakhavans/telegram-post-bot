# Telegram Post Bot

Telegram Post Bot connects an authorized Telegram bot to a WordPress REST webhook. It guides a user through a short post-submission flow and creates the result as a WordPress draft.

The project is intentionally small: configuration is environment-based, session state uses WordPress transients, and editorial publishing remains inside WordPress.
